# Screenshot capture plan

Use actual live analysis results. Do not insert synthetic weather or an invented risk score to make screenshots dramatic.

- **Hero:** desktop viewport, top of homepage, complete trip form visible.
- **Dashboard:** Ann Arbor → Chicago for a valid future departure; show route heading, risk gauge, recommendation, map, and departure comparison.
- **Map:** show the risk-colored road and a sample popup with forecast details. Keep OpenStreetMap attribution visible.
- **Mobile:** narrow viewport with the same real analysis, showing stacked metrics and a usable form.

A conceptual route illustration in the hero is labeled as an illustration; it is not a live result. Saved UI captures, when available, belong in `docs/images/` and should be linked from the README. No stock images or fabricated forecasts should stand in for application screenshots.
